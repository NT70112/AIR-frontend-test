# Тестовое frontend-задание для AIR.

Все взаимодействия пользователя с интерфейсом сделаны на нативном JS. Маска формы сделана с помощью библиотеки IMask.js (создана на нативном JS).

Адаптивный дизайн начинается с 380px.

Валидация формы включает:
- Проверку поля имени на ввод только буквенных символов.
- Проверку на пустые строки или недостаточную информацию в поле для номера телефона.
